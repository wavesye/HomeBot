# v0.7.1：左右独立 PWM 校准

v0.7 双电机台架测试已获用户确认通过，电机线调整后前后左右对应已解决。约 25% PWM 的落地视频仍有偏航，拍摄时 Pi 与充电宝未固定；用户判断左轮更快，但尚无两轮 RPM 测量。按用户要求，本版加入左右独立输出系数，实测补偿跑偏。

基本接线、四方向定义和停止流程沿用 [v0.7 文档](v0.7-drive.md)。GPIO23 继续留空，保留已验证的电机线接法与 `--invert-left` / `--invert-right`，无需因 PWM 校准再次改线。

## 1. 系数如何作用

| 参数 | 默认值 | 范围 | 用途 |
| --- | --- | --- | --- |
| `--left-scale` | `1.0` | `0 < scale <= 1` | A 通道左轮输出系数 |
| `--right-scale` | `1.0` | `0 < scale <= 1` | B 通道右轮输出系数 |

参数仅适用于 `--motor drv8833-dual`。每侧实际 PWM 幅度 = 网页基础 PWM × 该侧系数；前进、后退、左右转都按同一侧系数输出，invert 只改变极性。基础输出上限仍为 30%，系数只能减小输出，不能提高上限。

例如网页设为 25%，左右系数为 `0.98` / `1`，输出命令分别为左 24.5%、右 25%；这表示 PWM 幅度，不是转速。网页只读显示系数为左 98%、右 100% 并说明 PWM 计算方式，不显示实时两侧输出数值。STOP 撤销两侧输出，停止失败时状态显示未知输出并锁定。系数不相等时，左右转可能不再围绕原位置对称转动，需复核。

系数只在启动时设置，没有在线编辑或自动保存。下次启动必须沿用记录的完整命令；重启后输出为零，刷新页面后需明确发起新动作。滑块只影响下一次动作，拖动不会修改当前输出；心跳不改变基础 PWM 或系数。

没有编码器或航向反馈，本版属于手动 PWM 补偿，不能保证不同地面、载荷、电量下都严格直行，也不自动修正航向。

## 2. 同步到 Pi

当前修改在 Mac 工作区，尚未据此宣称已推送或部署。先断开电机电源 VM，在 Pi 上按 `Ctrl+C` 停止旧服务；调整固定或接线时正常关闭 Pi 并断开两路供电。

在 **Mac 项目目录**执行：

```bash
rsync -av --exclude='__pycache__/' server web docs README.md ROADMAP.md waves@wraspberrypi:~/homebot/HomeBot/
```

该命令只同步源码及文档，不同步 Mac 的 `.venv` 或 `.git`，保留 Pi 自己的环境。Pi 环境已能运行 v0.7 时，本版不需要新增依赖。

在 **Pi** 激活原环境、保持 VM 断开，再启动基线：

```bash
cd ~/homebot/HomeBot
source .venv/bin/activate
python -m server.run --lan --motor drv8833-dual --left-scale 1 --right-scale 1
```

若原命令含有已验证的 invert 参数，须一并添加；用户已通过改线解决方向，不根据历史问题盲目新增 invert。刷新页面，确认版本 V0.7.1、双轮上限 30%、左右系数显示 100%、页面显示 STOP 且基础输出状态为零、无 fault，再恢复 VM 供电。每次 LAN 启动访问码可能变化，使用当前终端打印的访问码。

## 3. 逐步校准

1. 全部断电，固定 Pi 外壳、充电宝、驱动板、电池盒与线材，避免载荷在运动中滑动。检查两轮是否蹭底盘、轮胎安装是否一致及支撑轮是否卡滞。
2. 先架空复核四方向与 STOP，保留已验证的极性设置。落地后选择相同地面、初始姿态、载荷和基础 PWM；继续用用户已试过的 25%，两侧系数 `1` 建立基线。
3. 分别短测前进和后退，各记录偏航方向和距离；每次动作间先 STOP、等待至少 0.5 秒并观察轮停稳。确认两轮都能稳定起动，不能凭一段视频认定哪侧 RPM 更高。
4. **若固定后前进仍稳定向右偏，可先试降低左侧**：断 VM，停止旧服务，再用下列试验命令重启。仍需保留原命令中的已验证 invert 参数。

   ```bash
   python -m server.run --lan --motor drv8833-dual --left-scale 0.98 --right-scale 1
   ```

5. 在网页明确把基础输出设为 25%，用相同起点短测并比较。`0.98` 只是小幅试验起点，并非实测最佳值；若仍向原方向偏，可每次再减小 `0.01`～`0.02`，若偏向反转则往回调。每次只改一侧系数，保持另一侧为 `1`。
6. 前进和后退分别验证，不能假定同一系数一定同时改善两者，也不能把后退的偏向直接套用为前进判断。若无法兼顾，记录各自结果，本版没有按前后方向分别保存系数。
7. 复核左右转、松手/STOP、心跳超时和正常退出；系数不等时转弯轨迹可能变化。将通过的完整启动命令及测试条件记录下来，之后每次启动显式沿用。

若降低输出后某轮起动费力、间歇停转或堵转，立即 STOP，恢复上一档并检查供电与阻力；不要继续降低另一侧到起动阈值以下，也不抬高 30% 上限。程序卡死或未能撤销输出时，仍需手动断开电池盒连接或取出电池。

软件验证不等同于真实底盘直行通过。固定载荷、Pi 同步与下列实测仍待用户执行；结果确认前不进入 v0.8。

| 项目 | 待记录结果 |

| 启动配置 | 完整命令，包括已验证的 invert 与左右 scale |
| 基线 | 基础 PWM、地面/载荷、电池条件；前进与后退各自偏向及距离 |
| 校准复测 | 每组系数对应的前进与后退结果，两轮能否稳定起动 |

| 停止与重启 | 松手/STOP、心跳超时及正常退出撤销两侧输出；重启不自动移动 |
